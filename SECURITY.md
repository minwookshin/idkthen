# Security

This preview reads editable text through macOS Accessibility in apps explicitly enabled by the user. Incorrect edits, stale focus, protected-field access and disclosure of writing are security-relevant reports.

Please send a private report to im.minwookshin@gmail.com rather than opening a public issue containing sensitive information. Include the version, a minimal invented reproducer, expected behavior and actual behavior. Do not send real writing, passwords, diagnostics with private information or signing keys. No response-time guarantee is offered.

Source previews are not notarized installers. General downloads remain closed until the release process verifies the final Developer ID signature, stapled notarization ticket, Gatekeeper assessment and compatibility evidence. Never disable Gatekeeper or remove quarantine to work around a distribution failure.
